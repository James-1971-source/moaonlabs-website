========================================
촬영용 프롬프트 모음 (복사·붙여넣기 전용)
2026 클로드 활용법 / 주간업무보고 실습
========================================

----------------------------------------
[실습 1] Chat — 엑셀 파일 분석
※ 01_주간매출.xlsx 를 채팅창에 드래그한 뒤 입력
----------------------------------------
첨부한 01_주간매출.xlsx를 분석해줘.

1. 전주 대비 가장 크게 변한 지표 3개
2. 확인이 필요한 이상치
3. 팀장에게 보고할 핵심 내용 3개

숫자와 근거를 함께 정리해줘.


----------------------------------------
[실습 2] Project — Project Instructions 에 입력
※ 지식 자료: 04_기존보고서.docx, 05_업무보고_작성규칙.txt
----------------------------------------
이 프로젝트에서는 모든 주간업무보고를 다음 규칙으로 작성한다.

- 핵심 실적 → 주요 이슈 → 다음 주 계획 순으로 작성
- 중요한 숫자는 반드시 전주 대비 증감과 함께 표시
- 과장하지 않고 간결한 비즈니스 문체 사용
- 확인되지 않은 원인은 단정하지 않는다
- 최종 보고서는 A4 1~2장 분량


----------------------------------------
[실습 3-1] Artifacts — 분석을 보고서 결과물로
----------------------------------------
지금 분석한 내용을 바탕으로
팀장에게 바로 보여줄 수 있는 주간업무보고를 만들어줘.

1. 이번 주 핵심 요약
2. 주요 실적
3. 이상 징후 및 이슈
4. 다음 주 확인사항

이 순서로, 별도의 결과물 형태로 작성해줘.


----------------------------------------
[실습 3-2] Artifacts — 부분 수정
※ 결과물에서 결론 문단을 드래그 선택한 뒤 입력
----------------------------------------
결론을 절반 길이로 줄이고, 숫자를 먼저 보여줘.


----------------------------------------
[실습 4] Cowork — 업무 전체 위임
※ 입력창에서 Cowork 선택 후 입력
----------------------------------------
이번 주 주간업무보고 작성 업무를 끝까지 진행해줘.

내가 제공한 매출 데이터와 회의 자료를 확인하고,
주요 실적과 이슈를 분석한 뒤,
기존 주간보고서 형식에 맞춘 최종 보고서를 만들어줘.

중요한 숫자는 원본과 다시 비교해서 확인하고,
판단이 필요한 부분은 임의로 결정하지 말고 나에게 물어봐.


----------------------------------------
[실습 5-1] Claude Code — 폴더 먼저 확인
※ 작업 위치: 바탕화면 \ 주간보고_실습
----------------------------------------
현재 폴더 안의 파일을 먼저 확인해줘.
파일을 수정하거나 새 파일을 만들기 전에,
어떤 자료가 있는지 간단히 정리해줘.


----------------------------------------
[실습 5-2] Claude Code — 보고서 생성
----------------------------------------
이 폴더의 자료를 종합해서 이번 주 주간업무보고를 작성해줘.

04_기존보고서.docx의 구성과 문체를 참고하고,
01_주간매출.xlsx와 03_업무진행현황.xlsx의 숫자를 분석해서
주요 실적, 이슈, 다음 주 계획을 작성해줘.

원본 파일은 수정하지 말고 새로운 결과 파일로 저장해줘.


----------------------------------------
[실습 5-3] Claude Code — 숫자 검증
----------------------------------------
3번 항목의 수치를 원본 엑셀과 다시 비교해서 검증해줘.
수정이 필요하면 결과 파일만 수정해줘.


----------------------------------------
[실습 6] Skill — Skill 지침 내용
※ Customize → Skills
----------------------------------------
주간업무보고 작성 규칙

- 사용자가 주간업무보고를 요청하면 적용
- 기존 보고서 양식을 우선 참고
- 핵심 실적 → 주요 이슈 → 다음 주 계획 순서
- 모든 핵심 숫자는 전주 대비 증감 표시
- 근거 없는 원인 추정 금지
- A4 1~2장
- 마지막에 사람이 확인해야 할 항목 별도 표시


----------------------------------------
[실습 6-2] Skill 적용 후 — 짧아진 요청
----------------------------------------
이번 주 주간업무보고 만들어줘.


----------------------------------------
[실습 7] Connector — 연결되어 있을 때만
※ 반드시 테스트 계정 사용
----------------------------------------
연결된 Google Drive에서 '주간업무보고'와 관련된
최근 자료를 찾아서 어떤 파일이 있는지 정리해줘.
