주간업무보고 작성 규칙 (영업2팀 / v3)

[1] 구성 순서
    1. 핵심 실적
    2. 주요 이슈
    3. 다음 주 계획
    4. 확인 필요 사항
    - 순서를 바꾸지 않는다.

[2] 숫자 표기
    - 모든 핵심 숫자는 반드시 '전주 대비 증감'을 함께 표시한다.
      예) 매출 1억 8,720만 원 (전주 대비 -5.7%)
    - 금액은 만 원 단위까지, 비율은 소수점 첫째 자리까지.
    - 원본 파일에 없는 숫자는 절대 만들어 쓰지 않는다.

[3] 문체
    - 과장하지 않는다. "폭발적", "역대급" 같은 표현 금지.
    - 간결한 비즈니스 문체. 한 문장 60자 이내.
    - 개조식(~함, ~예정)으로 통일.

[4] 원인 서술
    - 확인되지 않은 원인은 단정하지 않는다.
    - "불량으로 인해" (X) / "원인 확인 중" (O)

[5] 분량
    - A4 1~2장.

[6] 마지막에 반드시
    - '사람이 확인해야 할 항목'을 별도로 표시한다.
      (수치 검증 필요 / 팀장 판단 필요 / 외부 공개 여부 확인)

※ 실습용 가상 규칙 문서입니다.
