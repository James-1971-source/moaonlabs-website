    01 / 코드 확인

    수강생 코드 확인

    내 과제를 확인하거나 제출하려면 수업에서 안내받은 16자리 코드를 입력하세요.

    숫자(0–9)와 영문(A–F)으로 된 코드예요. 공백이나 하이픈이 있어도 돼요.

    코드와 입력 내용은 이 페이지에 자동 저장되지 않아요. 주소·연락처 등 과제에 필요하지 않은 개인정보는 입력하거나 첨부하지 마세요.
