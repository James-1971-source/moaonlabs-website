# 디자인 브리프와 관찰 근거

## 목표
AI를 활용해 여러 서비스를 제공하는 모아온랩스의 서비스 허브. 멋진 기술 스튜디오의 첫인상과 복지·교육 고객이 이해할 수 있는 쉬운 안내를 함께 제공.

## 참고 사이트
- Linear https://linear.app/: 브라우저 접근성 트리·실제 CSS에서 큰 헤드라인(데스크톱 h1 64px), 약 -1.4px 자간, rgb(8,9,10) 배경, 제품 중심 계층과 기능 섹션을 관찰. 해당 사이트의 스크린샷은 반복 타임아웃으로 전체 시각 비교를 완료하지 못함.
- Vercel https://vercel.com/: 접근성 트리와 데스크톱 스크린샷으로 헤드라인·넓은 공간·명확한 CTA·모듈형 기능 안내를 확인.
- Pageonbook https://pageonbook.kr/: 서비스 기능, 외부 링크, 운영자 이름·사업자번호·공개 문의 이메일·대표 전화 확인. 가격은 변경 가능성이 있어 본 사이트에 복제하지 않음.

## 재구성 원칙
1:1 복제 대신 사용자가 요청한 비슷한 인상의 독창적 브랜드 사이트로 재구성. 다크 네이비, 민트 액센트, 넓은 여백, 6개 서비스 카드, 사람 중심의 한국어 카피, 독창적 입체 리본. 타사 자산 다운로드 없음.

## 원본 → 로컬 매핑
- 참고 사이트의 헤드라인 계층·제품 탐색 방식 → / 메인 구성 (카피·구조·그래픽은 재설계)
- 페이지온북 서비스 정보 → /services/pageonbook/ → https://pageonbook.kr/
- 사용자 제공 사업 내용 → 나머지 5개 서비스 상세

## 실제 경로와 소유 파일
- /: src/app/page.tsx
- /services/[slug]/: src/app/services/[slug]/page.tsx
- /contact/: src/app/contact/page.tsx
- /privacy/: src/app/privacy/page.tsx
- 공통 화면·상호작용: src/components/moaon.tsx
- 서비스 데이터: src/lib/services.ts
- 디자인: src/app/globals.css
- 독창적 그래픽: public/sites/moaon/

## 알려진 공백
당작공 URL 미확인, 도메인·호스팅 미선정, 정식 로고·소개문구 사용자 승인 전. 실적·고객 수·고객 로고·확정 가격·출시일을 만들지 않음. S&J영상편집기는 제작에 사용하는 도구로만 명시하고 사용자 계정이나 편집기 주소를 노출하지 않음.
