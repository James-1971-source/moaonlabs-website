# 검증 결과

## 코드
- npm run check: ESLint 10개 파일 오류 0·경고 0
- TypeScript tsc --noEmit 통과
- Next.js 프로덕션 빌드 성공, 서비스 6개 정적 경로 생성

## 브라우저
- 서비스 상세 6개를 각각 열어 제목·내용·상태·문의 링크 확인
- PC 1440px, 모바일 390px에서 상세 6개 가로 넘침 없음
- 320px 문의 페이지 가로 넘침 없음
- 모바일 390px 홈 메뉴 열기·서비스 이동·닫힘 확인
- 준비 중 필터: 6개에서 업무자동화 1개로 전환 확인
- 상세 → 문의 이동 시 관심 서비스 자동 선택 확인 (업무자동화 및 영상)
- 테스트 문구가 mailto 본문에 반영되는 것 확인. 실제 이메일 발송은 하지 않음
- 페이지온북 외부 링크 target=_blank 및 HTTPS 주소 확인
- 데스크톱·모바일 화면을 실제 스크린샷으로 검토
- 히어로 WebP 로딩 완료 및 이미지 해상도 확인

## 범위
모든 브라우저·실제 스마트폰·스크린리더 전수 검증이나 보안 인증을 의미하지 않습니다. TXT 내려받기와 실제 메일 전송은 사용자 환경에서 최종 확인이 필요합니다.
