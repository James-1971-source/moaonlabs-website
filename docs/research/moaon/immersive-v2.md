# 모아온랩스 Immersive Edition 2.0

## 유지한 내용
서비스 6개와 분류, 상세 소개, 페이지온북 연결, 문의 메일 작성 방식. 준비 중 서비스 상태와 당작공 주소 확인 필요도 유지.

## 변경
- 정적 히어로 이미지를 Three.js WebGL 실시간 장면으로 교체
- 자체 Fresnel·스펙트럼 셰이더의 입체 코어, 3중 궤도, 6개 위성 및 입자
- 코어/네트워크 보기 실제 3D 배치 전환
- 포인터 시점 반응 및 스크롤 반응, 사용자가 제어하는 일시정지
- 장면 위의 서비스 링크와 기존 목록 상세 연결
- 서비스 카드의 포인터 조명·원근 기울기
- 스크롤 등장 연출·상단 읽기 진행선
- 전체 타이포·광원·다크 컬러와 회사 소개/문의 영역 재디자인

## 렌더링 정책
- WebGL 2 지원 브라우저 필요. 지원하지 않으면 기본 장식과 명시적 안내를 제공하고 서비스 탐색은 유지
- OS의 prefers-reduced-motion을 존중하고 3D는 정적 프레임으로 표시
- 일시정지, 화면 밖·탭 숨김 시 반복 렌더링 중지
- 모바일 초기 로드 시 입자 수 축소, 픽셀비 제한
- 데스크톱 최대 60fps, 모바일 최대 30fps 목표 제한 (실제 성능 보장 수치 아님)
- 외부 3D 모델·AI API·이미지 업로드·추적 도구 사용 없음
