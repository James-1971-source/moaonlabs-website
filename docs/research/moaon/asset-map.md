# 자산과 권리

- public/sites/moaon/hero-sculpture.svg: 자체 생성 3D torus knot mesh. 외부 자산/API 없음.
- public/sites/moaon/favicon.svg: 자체 생성 민트 diamond 마크. 정식 상표/로고로 확정된 것은 아님.
- 서비스 카드의 책·쇼핑백·웹·교육·영상·워크플로: React·CSS 및 Lucide 아이콘으로 자체 구성한 콘셉트 그림. 실제 상품·판매 실적 아님.
- PretendardVariable.woff2: npm의 pretendard 1.3.9 공식 배포에서 추출, SIL OFL 라이선스 동봉.
- 타사 사이트 이미지·브랜드 로고·홍보문구 복제 없음.
- 회사명·사업 영역·상태: 사용자 직접 제공.
- 대표·사업자번호·이메일·전화: pageonbook.kr 공개 하단 운영 정보에서 확인.
- 주거 상세 주소는 소개 사이트에 재게시하지 않음.

- hero-sculpture.webp: SVG를 로컬 Sharp로 렌더한 경량 표시용 파일 (307,646 bytes, 원본 SVG는 편집용 보존).
